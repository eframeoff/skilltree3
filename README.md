# SkillTree — SaaS-платформа геймифицированного No-Code обучения (прототип)

Любой прикладной навык — аэротруба, гитара, футбол, что угодно — превращается в
RPG-**дерево талантов** в стиле Path of Exile. Эксперт собирает программу в
визуальном no-code конструкторе; ученик «прокачивает персонажа» в реальной
жизни: изучает теорию, проходит тесты и сдаёт навыки **видео-аттестацией**
тренеру на 1–5★.

```
npm install
npm run dev      # http://localhost:5180
```

> Прототип: без бэкенда — мок-данные и in-memory store. Фокус — UI/UX обеих
> сторон платформы (конструктор автора + игровой клиент ученика), модель данных
> и движок дерева. Интерфейс адаптивный: телефон (нижняя навигация) и
> полноценный веб (сайдбар, многоколоночные раскладки, редактор графа).

---

## 1. Концепция: две стороны платформы

### Авторы и тренеры (`/coach`) — no-code конструктор
* **Мои деревья** — портфель программ: создание, черновик/публикация, инвайт-ссылка.
* **Визуальный редактор графа** (`TreeEditorScreen` + `EditorCanvas`):
  * узлы перетаскиваются по холсту (pan/zoom как в редакторах нод);
  * режим «Связи» — клик по двум узлам создаёт/удаляет пререквизит (циклы запрещены);
  * у каждого узла: тип (теория/практика/зачёт), уровень, описание, шаги
    инструкции, конструктор вопросов автотеста, флаг side-quest;
  * уровни дерева (ветки, открывающиеся последовательно) с цветами;
  * условие сдачи определяется типом узла:
    `test` → автотест в приложении · `practice` → видео, тренер одобряет ·
    `exam` → видео-экзамен с оценкой 1–5★.
* **Очередь проверки** — все pending-видео учеников по всем деревьям тренера.
* **Ученики** — ростер по (ученик × дерево), прогресс, дерево глазами тренера с выставлением оценок.

### Ученики (`/app`) — геймифицированный клиент
* **Каталог** опубликованных деревьев + запись в один клик; инвайт-ссылки `#/join/:treeId`.
* **Мульти-запись**: ученик качает несколько деревьев параллельно (София — аэротруба + гитара).
* **Дерево**: туман войны, дыхание доступных узлов, гейты уровней, боссы-зачёты.
* **Игровой цикл узла**: теория → автотест в приложении → запись практики →
  отправка тренеру → точечный фидбек в контекстном чате узла → 1–5★.
* **Видео-паспорт**: портфолио сданных навыков + подборка хайлайтов для соцсетей (Фаза 2 — авто-нарезка).

## 2. Демо-данные

3 автора, 6 учеников, 3 опубликованных дерева (движок одинаково обслуживает все ниши):

| Дерево | Автор | Уровни |
|---|---|---|
| 🪂 Аэротруба: от новичка до Pro (50+ узлов) | Мара Восс | ЖИВОТ → СПИНА → HEAD UP → HEAD DOWN → DYNAMIC |
| 🎸 Гитара с нуля до первого соло | Лука Морено | БАЗА → РИТМ → СОЛО |
| ⚽ Футбол: техника и дриблинг | Дмитрий Сокол | ТЕХНИКА → ДРИБЛИНГ → ИГРА |

Вход без пароля — выбор профиля на `/login`.

## 3. Архитектура фронтенда

```
src/
├── data/
│   ├── treeUtils.js        # чистый «движок»: edges, гейты уровней, unlock-pass,
│   │                       #   статистика, фабрики конструктора, защита от циклов
│   ├── trees/              # деревья = сериализуемые JSON-определения
│   │   ├── windtunnel.js   #   (то, что редактирует конструктор и будет
│   │   ├── guitar.js       #    храниться в БД)
│   │   └── football.js
│   └── users.js            # авторы, ученики, enrollments, сиды прогресса/видео/чатов
├── context/
│   ├── AuthContext.jsx     # мок-аутентификация (выбор профиля)
│   └── StoreContext.jsx    # глобальный store: деревья (редактируемые!), прогресс
│                           #   (только ФАКТЫ: completed/in_progress — остальное
│                           #   derived), видео, чаты, действия конструктора
├── components/
│   ├── AppLayout.jsx       # адаптивный shell: сайдбар ≥lg, нижняя навигация <lg
│   ├── SkillTree.jsx       # pan/zoom канвас просмотра (любое дерево через props)
│   ├── EditorCanvas.jsx    # канвас РЕДАКТОРА: drag узлов, режим связей
│   ├── TreeView.jsx        # дерево + NodeDetail + действия (ученик/тренер)
│   ├── NodeDetail.jsx      # карточка узла: описание/теория/тест-или-попытка/чат
│   │                       #   (на десктопе — правый drawer)
│   └── …                   # SkillNode, ContextChat, StarRating, ui, icons
└── screens/
    ├── LoginScreen.jsx · JoinScreen.jsx (инвайт-лендинг)
    ├── student/    Dashboard · Catalog · Tree/:treeId · Videos
    └── instructor/ Dashboard · Trees · Trees/:id/edit · Students(+Detail,Tree) · Videos
```

**Ключевой принцип store:** прогресс хранит только факты
(`completed` / `in_progress`); `available` / `locked` вычисляются на каждое
чтение (`recomputeProgress`). Поэтому правка дерева автором мгновенно
перестраивает карту разблокировок всех его учеников.

## 4. Модель данных (Фаза 2 — PostgreSQL)

Полная схема: [`db/schema.sql`](db/schema.sql). Мульти-тенантность:
`skill_trees.author_id` + `status (draft/published)` + `invite_code`;
`tree_levels` — последовательные гейты; `nodes.quiz/steps` (JSONB) — контент
автотестов; `enrollments (student, tree, coach)` вместо жёсткой привязки
ученик→инструктор. «Много черновиков — один зачётный ролик» enforced частичным
уникальным индексом по `video_submissions`.
