# SkillTree — инструкция для тестирования

Это гайд для тест-группы: **тренеры** строят дерево навыков и проверяют сдачи,
**ученики** проходят дерево и загружают свои попытки (фото / видео). Цель теста —
пройти полный круг: *тренер опубликовал → ученик загрузил → тренер оценил*.

---

## 0. Как открыть приложение

Открой ссылку, которую дал организатор теста, в браузере (лучше Chrome).
- На телефоне и на компьютере работает одинаково.
- Если открываешь по локальной сети (адрес вида `http://192.168.…`) — это нормально,
  загрузка фото/видео из файла работает.

> Регистрации пока нет — на входе ты **выбираешь готовый профиль**. Организатор
> скажет, под каким персонажем ты тестируешь, чтобы вы не пересекались.

---

## 1. Вход

На стартовом экране — два списка: **Авторы и тренеры** и **Ученики**.
Нажми на свой профиль — вход произойдёт автоматически.

| Роль | Профиль | Что у него есть |
|---|---|---|
| Тренер | **Мара Восс** | дерево «Аэротруба» с учениками |
| Тренер | **Лука Морено** | дерево «Гитара» |
| Тренер | **Дмитрий Сокол** | дерево «Футбол» |
| Ученик | **Алекс / София / Елена / Ника** | записаны к Маре (аэротруба) |
| Ученик | **Маркус / Джек** | записаны к Дмитрию (футбол) |

Рекомендация для группы из 5 человек: **1 тренер = Мара**, **4 ученика =
Алекс, София, Елена, Ника** (все на одном дереве — тренер увидит всех в одной
очереди проверки).

## 2. Сценарий для УЧЕНИКА

1. После входа ты на своём дашборде — открой своё дерево (карточка курса).
2. **Дерево навыков** — это карта. Узнаваемо:
   - круг — теория/тест, квадрат — практика, шестиугольник — зачёт;
   - цвет = состояние: тускло-серый «заблокировано», голубой «доступно»,
     зелёный/фиолетовый/золотой «пройдено» (чем выше оценка — тем ценнее цвет);
   - размытые узлы со знаком «?» — ещё закрыты («туман»), откроются по мере прогресса.
   - кнопка **«К цели»** (вверху справа) — перебросит камеру к ближайшему доступному навыку.
3. Нажми на **доступный** (голубой) узел → откроется карточка с вкладками:
   - **Описание** — что надо сделать;
   - **Инструкция / Теория** — материалы тренера;
   - **Попытка / Тест** — здесь ты сдаёшь;
   - **Чат** — переписка с тренером по этому узлу.
4. **Загрузи попытку** (вкладка «Описание» или «Попытка»):
   - нажми **«Выбрать файл»** → выбери **фото или короткое видео (до 50 МБ, ≤30–60 сек)**;
   - можно добавить комментарий;
   - **«Загрузить попытку»** / **«Отправить зачёт»**.
   - Узел станет «на проверке» (жёлтый таймер). Жди оценки тренера.
5. Для узлов-**тестов** (круг) — пройди вопросы во вкладке «Тест».
6. Когда тренер примет — узел станет цветным, откроются следующие. Во вкладке
   «Попытка» → переключатель **«Все попытки»** покажет историю с оценками и
   причинами отказов.

**Что протестировать:** загрузку фото И видео; повторную попытку после отказа;
чат с тренером; открытие новых узлов после сдачи.

## 3. Сценарий для ТРЕНЕРА

### A. Проверка сдач (главное)
1. В меню тренера → **«Проверка видео»**.
2. Вкладка **«Проверка»**: слева очередь (дольше всех ждущие — сверху), справа —
   текущая сдача. **Медиа реально проигрывается / фото показывается.**
3. Оцени: звёзды **1–5** (можно с горячих клавиш `1`–`5`), либо **отклонить**
   с причиной (уйдёт ученику в чат). `←/→` — листать очередь.
4. Тумблер **«По узлам»** — сгруппировать очередь, чтобы судить один навык у всех
   по единой планке.
5. Вкладка **«Очно»** — навыки, которые сдаются вживую: отметь результат на месте.

### B. Своё дерево (конструктор)
1. Меню → **«Мои деревья»** → открой дерево или создай новое.
2. На пустом холсте — **быстрый старт**: шаблон или «импорт списка навыков»
   (каждая строка — навык, `# Название` — уровень, `*` в конце — зачёт).
3. Инструменты: **+ Узел**, **Связи** (соединить пререквизиты), перетаскивание,
   рамка-выделение (Shift-протяжка) для групповых правок, **миникарта**,
   поиск `Ctrl/Cmd+K`, отмена `Ctrl+Z`.
4. Клик по узлу → справа настройки: название, тип, **как учить / что принимать /
   как оценивать**, делегирование наставникам.
5. **«Опубликовать»** — дерево появляется у учеников. Дальнейшие правки идут в
   черновик; **«Опубликовать изменения»** показывает, кого они затронут.

**Что протестировать:** проверку фото и видео; приёмку и отклонение; создание
дерева из шаблона/импорта; публикацию.

---

## 4. Ограничения теста (это нормально)

- **Видео — только короткие** (≤50 МБ). Длинные не загрузятся (увидишь
  предупреждение). Фото сжимаются автоматически.
- **Аккаунты общие** (нет регистрации) — каждый тестер берёт свой персонаж, иначе
  будете мешать друг другу. Прогресс сохраняется в базе по каждому персонажу.
- Видео-инструкции тренера и «нарезка-подборка» — пока заглушки.

---

## 5. Что прислать организатору после теста

- Что было непонятно / где застрял.
- Загрузка фото и видео — быстро/медленно, с какого устройства.
- Что сломалось или повело себя странно (со скриншотом, если можно).
- Понятна ли механика дерева: где ты, что доступно, что дальше.

---

## Для организатора (тех. часть)

- **Доступ к приложению.** Для удалённых тестеров — задеплой фронтенд
  (Vercel / Netlify / Cloudflare Pages, бесплатно; переменные `VITE_SUPABASE_URL`
  и `VITE_SUPABASE_ANON_KEY` — в настройки проекта). Быстрый вариант в одной сети:
  `npm run dev -- --host` и раздать `http://<твой-IP>:5173`.
- **Данные.** Демо засеяно `node scripts/seed-supabase.mjs` (пароль всех
  персонажей — `skilltree123`, вход через выбор профиля). Повторный запуск
  пересоздаёт демо-данные (загруженные тестерами попытки при этом сотрутся).
- **Расход Supabase.** Следи за **Settings → Usage** (бесплатно: 1 ГБ хранилище,
  5 ГБ трафик/мес — для 5 тестеров с короткими видео хватает).
